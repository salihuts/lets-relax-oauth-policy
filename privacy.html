Privacy Policy — Let's Relax YouTube Automation

Last updated: 2026-10-25

Let's Relax YouTube Automation ("this application") is a private, personal-use tool built and operated by the owner of the Let's Relax YouTube channel (youtube.com/@Lets-Relax) to manage that same channel's own content. It is not a public product, is not distributed to any other party, and is not used to access any YouTube account other than the owner's own.

What this application does

With OAuth authorization granted directly by the channel owner, this application calls the YouTube Data API v3 to:

  • Post comments (e.g. a pinned first comment) on videos uploaded to the Let's Relax channel, on the owner's own behalf.
  • Read and update video metadata (title, description, tags) for videos already owned by the Let's Relax channel.

All actions are initiated manually by the channel owner — there is no automated or scheduled posting without a human triggering the action, and every value written to YouTube is reviewed by the owner before it is sent.

OAuth scope requested

This application requests a single scope:

  • https://www.googleapis.com/auth/youtube.force-ssl — required to post comments and update video metadata on the authorizing channel's own videos. No broader scope (e.g. account deletion, channel transfer, monetization settings) is requested or used.

What data this application accesses, and how it's stored

Only data belonging to the authorizing YouTube channel itself: that channel's own video details, comment threads, and channel information as returned by the YouTube Data API for the actions above. This application does not collect, view, or process data belonging to any other YouTube user, viewer, or commenter beyond what the API itself returns as part of a normal channel-management call (for example, the text of a comment this application posts on the owner's behalf).

OAuth credentials (client ID/secret and refresh token) are stored only in a local, non-public configuration file on the channel owner's own machine. They are never transmitted anywhere except directly to Google's own API endpoints over HTTPS, and are never logged, backed up to a third party, or shared. The owner can revoke access at any time at myaccount.google.com/permissions, which immediately invalidates the stored refresh token.

Data retention

Credentials are retained locally only for as long as this application remains in active use by the channel owner. No user data obtained through the API is retained after the single action (posting a comment, updating metadata) that required it completes — this application does not maintain a database or long-term store of YouTube data.

Data sharing

No data obtained through this application or the YouTube Data API is sold, rented, or shared with any third party for any purpose, including advertising.

Limited Use disclosure

Let's Relax YouTube Automation's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
