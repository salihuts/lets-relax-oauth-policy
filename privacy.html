Privacy Policy — Let's Relax YouTube Automation

Last updated: 2026-10-24

This application is a private, personal-use tool connecting to the Let's Relax YouTube channel's own account via the YouTube Data API v3. It is not a public product and is not distributed to or used by anyone other than the channel's own owner/operator.

What it does

Using OAuth authorization granted directly by the channel owner, this tool posts video comments and updates video metadata (title, description, tags) on videos belonging to this same YouTube channel, on the owner's own behalf.

What data it accesses

Only data belonging to the authorizing YouTube channel itself: video details, comment threads, and channel information accessible through the scopes the owner explicitly grants. No data belonging to other YouTube users, viewers, or commenters is collected, stored, or processed by this tool beyond what the YouTube API itself returns for normal channel-management actions (e.g. the text of a comment this tool posts).

Data sharing

No data is sold, shared, or transmitted to any third party. Credentials are stored locally and used solely to call Google's YouTube Data API on the owner's behalf.

Contact

Questions about this policy can be directed via the Let's Relax channel's About page.
